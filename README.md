# mod_signal_lost

Repeated my Cold Boot experiment, but this time with Gemini instead of ChatGPT.

The project lost cohesion at one point, but I hauled it back from the brink of complete dissolution by selecting a new roster of instruments and reminding Gemini about the patterns it had written. Compared to ChatGPT's effort, I had to intervene a lot.

Considering what it went through, I think it sounds ok. It would work fine as a loading-screen tune, which after all was the brief. I might replace the `DigDug` sample.
